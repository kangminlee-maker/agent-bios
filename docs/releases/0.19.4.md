# agent-bios 0.19.4

Release changes relative to 0.19.3.

## Current model bindings

Six of the eight role bindings named a previous-generation model. The shipped
launch profile now binds:

| Seat | Claude | Codex |
| --- | --- | --- |
| FRONTIER | `claude-fable-5-1` · max | `gpt-6-astra` · max |
| HELM | `claude-opus-5-5` · high | `gpt-6.1-sol` · xhigh |
| WORKHORSE | `claude-sonnet-5-5` · high | `gpt-6.1-sol` · high |
| SWEEP | `claude-haiku-5-5` · medium | `gpt-6-luna` · max |

The Claude HELM and WORKHORSE seats move down one effort step with the rebind. The
5.5 models recalibrate their levels and think more per turn at a given level, so
carrying `xhigh` forward would buy longer turns rather than more depth. SWEEP now
states its effort instead of following the vendor default, because Haiku 5.5 takes
the same effort vocabulary as the other seats.

The Codex catalogue retired `gpt-5.6-terra` without a same-role successor, so
WORKHORSE shares HELM's model and differs by effort alone. A review dispatched to
that seat no longer adds a second model's perspective; the guides say so where the
seat is named.

The deep reviewer that the Deep review and Session distill presets dispatch from a
Claude session is now `gpt-6.1-sol` at `ultra`. `ultra` is not the rung above
`xhigh`: the Codex CLI catalogue reports it as maximum reasoning with automatic task
delegation, a different mode, and `gpt-6-luna` refuses it.

Presets you saved yourself live in `~/.config/agent-launch/presets.local.toml`,
which installation never deploys or verifies. A saved preset that overrides a seat
with an older model keeps that override after the upgrade.

## Model currency is checked against the host catalogues

A model-currency check reads the model catalogues the Claude and Codex CLIs
already cache on disk, so judging whether a binding is current needs no
network and no API key. Structure blocks: every bound model must carry a row in
the profile's `[models]` table, an unused row fails, and the agent definitions
must agree with the profile. Currency only discloses during development, because a
model going stale is the vendor's action rather than a defect in the tree.
Publishing is where it blocks: `prepublishOnly` refuses a package whose bindings
the catalogues have moved past.

Moving the bindings surfaced pre-existing defects that are fixed here:

- `session-cost.py` matched prices by model-name prefix, so `claude-opus-5-5` was
  billed at the Opus 5 rate, and `claude-sonnet-5` carried another model's rate,
  overstating Sonnet 5 sessions by half. Prices now match the exact model id,
  optionally with a release-date suffix, and controls hold the rule.
- The launcher hard-coded a model name in two places, so an effort restriction it
  encoded never applied to the model that replaced it.

## Prompting guides re-derived

`claude-prompting.md` and `gpt-prompting.md` were re-read against their vendor
sources rather than re-pinned: all three Claude seats now have their own vendor
page, and four of the five pinned documents had moved. The multi-model workflow
guide was updated for the shared Codex seat.

## Python 3.12 is the stated floor

`launch/agent-launch.py` has required Python 3.12 since 0.19.0, while the
documentation, the installer and the setup checks said 3.11. The stated floor is
now 3.12 everywhere it is stated, and the installer and the UI loader check for
it. The bundled UI wheels still declare 3.11, which they support; that is no
longer the package's floor.

## Installation messages

- `agent-bios update --check` run from a directory deleted under the shell
  reported that the registry was unreachable, although npm never started there.
  The check now moves to `$HOME` first.
- The macOS and Linux installation command ended its success line with the whole
  help text, because it asked for a `--version` flag the command does not have.
  It now reads the version npm installed, and says when it cannot.

## Upgrading

```bash
npm i -g agent-bios@0.19.4
agent-bios install
```

Install the exact version: right after a release, `@latest` can still resolve to
the previous one.

## Not established by this release

Model currency is judged against the catalogues on the publishing machine at the
time of publication; a model released later is not reflected until the next
release. The Windows script route, its unsigned preview channel and the Claude
Desktop route are unchanged from 0.19.3, with the same unestablished points.

Domain knowledge, Decision memory and shared environment editions remain design
directions rather than features of this release.
