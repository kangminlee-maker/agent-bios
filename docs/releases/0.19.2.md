# agent-bios 0.19.2

Release changes relative to 0.19.1.

## Korean writing guidance

The core library includes `korean-writing`, a relevant guide consulted before Korean
writing, revision, or translation. Twelve principles and Korean golden examples
cover meaning preservation, evidence and uncertainty, terminology, conditions,
proposal/completion distinctions, and UI wording that matches actual behavior.
The guide applies to responses, documents, slide wording, and UI copy. Selection
and per-item disablement remain explicit; routing is not proof of model reading.

## Instructions naming and upgrade compatibility

The rules, guides, and procedures component is named **Instructions**, and its
management UI is **Instructions Studio**. The canonical CLI is
`agent-bios instructions`; launcher, setup and app guidance use the same naming.

Older interfaces continue to work against the same implementation and store.
Conflicting old/new environment settings are rejected instead of choosing another
store. Existing storage locations, serialized identities, session pins and the
shared writer lock are preserved. Old-release launcher and app-bridge adapters
remain available during upgrades. This compatibility layer is a future removal
item, subject to the [documented removal conditions](../instructions-compatibility.md#removal-condition).

The conversational setup guide names the actual retained-inventory response fields,
so the agent can present previously stored personal instructions during setup.

## Product scope

The documented purpose centers on selecting, sharing and continuing team work
environments. The implemented product remains the Instructions library and host
launch/delivery integration. Domain knowledge, Decision memory and shared environment
editions are design directions, not features introduced by this release.

Interactive setup, language selection, app connection and local instruction capture
were already available in 0.19.1.
