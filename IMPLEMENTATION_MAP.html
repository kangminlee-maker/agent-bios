Private managed corpus

Agent-bios keeps its authored corpus in a private package release and resolves it only for an explicit agent-bios launch. The catalog gives every current rule, guide, skill, hook, and agent a stable ref; the store combines that immutable baseline with personal items and host-specific learning events, then compiles a content-addressed snapshot. Native Claude and Codex homes remain their own authority. Vanilla and plain CLI receive no added agent-bios corpus. --corpus-native is a default-off Claude path that emits validated namespaced per-item plugins for installed hook and agent carriers; it is distinct from launcher tier agents. User-global instructions are included by default; Claude can selectively exclude them, while Codex retains native loading. Authenticated Claude startup and managed resume loading are verified without a model-generation request; corpus-agent execution remains unverified.
