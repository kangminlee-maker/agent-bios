Private instructions and explicit session delivery

This map describes current structure and the authorities that implement it. Live release, test, and machine state come from the commands below. The decision ledger owns decisions; FINDINGS.md owns unresolved product questions.

InstallationTerminal or conversation setup starts with an English, Korean or Japanese language choice, then reviews dependency actions and instructions selection before Apply. Native instruction files are preserved; optional app skill discovery is explicitly selected.
ActivationCLI launches use a selected snapshot and host evidence. Codex app tasks explicitly request context through the app bridge. No-instructions selection supplies no body or bootstrap.
OwnershipPersonal sources, installed baselines, snapshots, and session pins have separate lifetimes. Optional shell connection and explicit legacy migration have scoped ownership checks.

CLI source to session

Existing global agent-bios installations need explicit migration before a bare native launch can be described as free of their old projection. Installation alone does not retire legacy exposure.

Delivery and verification boundaries

SurfaceCurrent behaviorWhat it does not establish
User global instructionsIncluded by default. Claude supports selective exclusion for configured sessions; Codex retains native loading. Files are preserved.Excluding agent-bios content does not remove the user's native or project instructions.
Native instructions hooksDefault-off --instructions-native. One canonical carrier, host-supported events, Claude per-item plugins, Codex session configuration. Host trust remains in force.Storing or registering a hook does not prove an invocation.
Authored instructions agentsSelected Claude plugin agents use a separate opt-in from launcher tier-agent configuration.Agent frontmatter translation to Codex and generic body-execution evidence are separate concerns.
Private verifyChecks stored release bytes, catalog, baseline, and owned projections.Reports activation as unverified; it is not a model-compliance test.
Snapshot and session pinExact source/file identity and observed host session id support reproducible resume.A pin does not prove that all instructions were followed or inherited by a child.
Structural gatesCheck declared contracts against nonempty subjects; negative controls must fail by name.A green gate is limited to its subject set and assertions. Semantic completeness requires evidence-based review.
