# Stage 0 build plan — tier-economics experiment instrument

Implements Stage 0 of `2026-09-03T2215--a477bcc--tier-economics-write-experiment.md`
(revision 7, sha256 `75232724d140`): the instrument only, every blocking control proven
by a planted failure, every disclosing control implemented as a flag. No cell counts
until this plan's done-when holds.

## Where it lives, and what it reuses

`benchmarks/tier/` — a sibling of the instruction-behaviour benchmark, author-side
(`check-package.sh` declares `benchmarks/` unshipped). It reuses, by import from the
parent directory: `dispatch` (pinned-seat execution, `real_bin`, `seat_problem`,
`model_matches`), `receipt` (the response-receipt contract), `fixture_state` (pristine
snapshots), `manifest` (declare-before-dispatch, bijection), `judge.probe_all` (the
known-bad probe). Vocabulary is reused before it is added: a *run* is one cell response
with its participants; a *receipt* gains a `participants` list; the *manifest* gains the
experiment pin; `defect:*` statuses are the infrastructure-failure class; the *judge* is
the checker; a *probe* is a planted failure.

New names, each with its reason: **participant** (a parent, child, or fork with its own
artifact — the ledger's unit, which no existing concept carries), **level measure**
(defects on held-out checks — not a postcondition, which is visible), **brief protocol**
(standard / cheap-seat — a treatment column), **done-when failure** (a run short of its
visible checks after the repair budget).

## Slices, in order

Each slice ships with its negative controls and is run against real artifacts before the
next starts. A slice's done-when is machine-checkable.

**S1 — usage, rates, reconciliation (controls 5, 2; the ledger's arithmetic).**
`tier/usage.py`: participants from artifacts on both hosts; per-request kinds; the
partition identities; participant-indexed, per-request pricing with the Codex cliff;
reconciliation against Claude `total_cost_usd`. Goldens from captured real payloads with
distinct nonzero sentinels and hand-calculated dollar totals; every single-field
omission or swap mutation, aggregate-before-pricing, swapped participant→seat, and
wrong-seat rate must fail by name. Done-when: `tier/selftest.py --s1` green with every
mutation failing, and a live haiku parent + child run reconciling within 3%.

**S2 — experiment pin and seat receipt (control 4, blocking).** Pin = HEAD, sha256 of
`launch/agent-launch.toml`, of each agent definition, of the child body, of both brief
templates. Per participant: model, effort, body hash, protocol hash read from the
artifact and compared to the pinned row; three planted mutations (model, effort-only,
body) fail by name. Done-when: the effort-only mutation is refused on both hosts.

**S3 — fixture generator and checker (controls 3, 7, 10, blocking).** A dependent batch
of M items in one module family (Python, pytest): per item a visible failing test, a
regression check, ≥2 held-out tests, and the faithful fix. Control 7 both directions and
every assertion; control 10 leak with two plants; control 3 the ITT denominator with
every assigned identity receipted after each repair pass. Done-when: M=10 L2 generated,
faithful fix passes everything, both mutations fail the named assertion, leak plants
fail by name.

**S4 — brief templates, run ledger, repair protocol, level scoring (control 0).**
Standard and cheap-seat templates filled by the parent inside the run; participant
enumeration against the row; completeness (terminal record, per-turn = cumulative);
self-verify ≤2 and parent repair ≤1; level measure from held-out checks; the missing-child
and cut-before-terminal plants. Done-when: a delegated probe run on each host publishes
a ledger, and both plants are refused by name.

**S5 — Stage-0 probe runs.** Standing-prefix length per seat (the cache band), the
Claude known-opposite seat spread from both estimators, the Codex differential probe,
disclosing flags rendered in a verdict's first lines. Done-when: every blocking control
shown failing on its plant and passing on the real path, on both hosts; disclosing
controls emit their flags on a planted condition.

## Mock boundary

Goldens are captured real payloads, not authored; mutations are applied to copies inside
`selftest.py` and nothing in the runtime path reads them. No provider is simulated: the
only realizations are `live` (a host binary) and `golden` (a frozen real payload in the
self-test). Mock-backed checks are reported as such and count for the instrument only.

## Stop conditions

A review or self-test finding that widens a control's purpose or moves a concept
boundary stops the slice for a decision. Two failed attempts at one control escalate.
Spend on live probes is bounded to the haiku seat until S5, where each host's shipped
and HELM seats are exercised once.

SpawnGate: parallelism WORKHORSE inline — S1 and S3 are independent, but the operator's
standing no-fan-out holds for this initiative; S3 starts when S1's done-when is green.
SpawnGate: independence FRONTIER inline — the design itself carried three cross-family
rounds; this plan is process, and its first real check is S1's live reconciliation.
