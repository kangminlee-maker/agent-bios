## Traps this session paid for

- **`git mv` writes the index.** It nearly killed a running gated commit — the hook's new
  tree comparison would have refused it. The index was restored by resetting only the two
  renamed paths to HEAD, leaving the rename in the working tree. Index-writing commands are
  `add`, `reset`, `add -N`, `mv`, `rm`, `restore --staged`, `stash` — hold all of them while
  another gated commit is in flight.
- **`$var` does not word-split in the Bash tool (zsh).** A loop passing `--scenarios "$SEC"`
  produced four uniformly empty comparisons that looked like "no regressions anywhere".
- **`python3` is not the interpreter the gate runs.** `check-parity.sh` runs
  `"$VENV/bin/python" gates/check_parity.py`; the system python has no Textual, so a direct
  `python3 gates/check_parity.py` reports a vacuous FAIL that is an instrument artifact.
