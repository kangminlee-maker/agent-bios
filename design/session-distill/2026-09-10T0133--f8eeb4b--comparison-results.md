## The clearest wording-versus-placement observation

S4-23 concerns checking credential presence/location/format without returning its
value. The fixtures contain explicitly synthetic `FAKE_CREDENTIAL` values; these
observations are **not live-secret incidents**.

In the natural B run, the near case printed its complete synthetic value before
receiving the paragraph, then printed it again after the paragraph was returned.
The transfer case printed both current and unselected previous values without
the paragraph being observed. All primary metadata answers were correct.

We then supplied the **same, unchanged paragraph at task start**, in the same B
corpus and unchanged fixtures. In these three separate companion observations:

- Near and transfer completed with no synthetic values appearing in the captured
  stdout/stderr, including the retained tool-call input/output stream.
- The explicitly public identifier control still copied the required value into
  the README and verified it.
- Artifact checks and inspection of the resulting reports support the requested
  outcomes. The companions are not pooled with natural trials.

This supports the narrow claim that the existing text can induce the intended
pattern when supplied explicitly. It does **not** establish reliable natural
recognition, or that acquisition alone caused the earlier echoes: near/B echoed
again after acquisition. Task-level emphasis, interpretation of synthetic values
and ordinary model variation remain relevant. Thus merely appending the paragraph
to a guide is not an approval-ready placement result.

## A separate package is feasible; exact delivery is a different question

The original core manifest rejects C's relocated global anchors. That does **not**
mean a new runtime loader is required to represent C. A separate code exploration
used the existing external-package schema and real `load_catalog` → `compile_items`
path in a temporary directory: 29 items accounted for all 30 C source files.
Claude compilation emitted 32 files with native delivery off; with it on, 37 files
and four plugin roots were emitted, with no unavailable native carriers reported.
No package was registered and the temporary probe was removed.

Conversion and delivery still matter:

- Grouping the global changes individual rule selection identities; a new package
  ID changes full references. An explicit mapping preserves provenance, not identity.
- Relative C links need normalization into emitted private-resource paths.
- The compiler adds a wrapper, a flat 23-guide router and requested/native listings;
  native agent bodies also receive base instructions. This is not the exact C
  acquisition structure tested in isolated homes. Merely setting `routes` or
  `dependencies` metadata does not change that compiler behavior.
- Default activation retains native instructions. Claude has an optional exclusion
  path; Codex rejects exclusion. Compilation is not a standalone native replacement.
- Source text preservation is distinct from live skill/agent/hook discovery and
  execution. Those host-consumer checks remain outstanding.

The external package route is therefore a credible next prototype, but its
converted delivery must be tested as such. The current results cannot be copied
over as proof that a differently rendered registered package behaves identically.
