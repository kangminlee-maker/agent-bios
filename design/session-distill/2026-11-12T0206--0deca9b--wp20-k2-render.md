# WP-20 K2: the review is S4's population, each member once, ranked by ranking.py and copied for the owner

The second package of WP-20 on `wp/20-review` (plan WP-20 done-when 1 and 8's frozen proposals; release-1
amendment 2026-11-11T0040), over lane L's S7 at 49fce8c (merged as 0deca9b). `runlib/stage_render.py`,
`distill.py render`.

## What landed

- **Rows from the population, never from proposals.json.** Every candidate of `population.json` is one row or one
  member of a group row; every rejected finding a row; every item a stage record holds as quarantined a row; every
  non-finding an appendix row with its locator (`<session file>#<record>`). A candidate S5's checks failed, S6 did
  not derive, or S7 returned is a row of the failed group with its stage and codes. A proposal for an id outside the
  population must be a planted control (`PROPOSAL_UNACCOUNTED`). Missing members `RENDER_INCOMPLETE`, repeated ones
  `RENDER_DUPLICATED`, each by id; S7 that neither proposed for nor returned an admitted candidate, S6 that judged and
  neither derived nor named not-derived, a source S6 never judged and never left out: each `RENDER_INCOMPLETE`.
- **The owner's legacy rule** (relayed by the lead 2026-11-11; recorded by lane L as D-20261111-e53a01): an incubating
  legacy entry not judged defaults to `none`. It is its own row when it carries a classification block or S7 proposed
  something other than `none` for it, and the row carries that proposal; S7's code-made `none` default (WP-12
  9146381, no call for an unclassified entry) keeps it in its group, one group row per first word of its legacy
  `decision1`, read from the pinned ledger through S4's own `lifecycle_intake.ledger_of`; one S7 returned is a failed
  row. A first word outside the owner's three is still a group and is named in the header. Other sources S6's sample
  left out are one group row per source (lead Q2 default). One decision on a group row applies to every member, whose
  ids the appendix lists.
- **Counts held to their producers** (`COUNTS_DIVERGE`, by count): candidates per source, formed members,
  rejected-finding members, non-findings per reason against S4's `population.counts`; each source S6 left out against
  the members and legacy rows the review shows unjudged for it.
- **Every row a review row**: every O6 field (`schemas/propose.schema.json`'s `reasons` owns the list), the test state
  S6 named (`untested: s8_deferred`), S7b's state (`absent` here; WP-12's S7b is merged after this package), both
  judges, the units with delivery evidence (release 1's named waiting state), the disputed judgments as numbered
  labels (each requirement the judges did not both mark met; the owner's own value met or unmet).
- **Hashes**: `payload_sha256` over the row's English source (the row without the O6 text, S7's Korean `reasons` and
  `artifact_set.korean`); `item_sha` over all of it, so a regenerated Korean field makes an earlier decision stale.
- **Order** through `runlib/ranking.py` (lane L owns it); the header names release 1's fallback (no test results, so
  the judges' and S7b's keys only). Rows ranking cannot place are reported by its own codes before `ranked` is
  called, so no refusal of it is caught here.
- **Awaiting R** (D-20261111-c48e9a reverses D-20261111-6d8152: the lead decided E4 is option b): a core item admitted
  by adjudication is shown awaiting R as S7 marks it, never eligible, in no F of the run, staying incubating.
- **The files of a version, each written once**: `review.ko.v<n>.md`, `decisions.ko.v<n>.md`
  (`grammar/owner_lines.copy_of`), `frozen-proposals.v<n>.json`, and `review.v<n>.json` last (the rows, the counts,
  the render's sha256, the frozen proposals' sha256, the previous version's rows sha256, and the spec
  `owner_lines.parse` holds the owner's lines to). A version any of whose files exists is refused
  (`RENDER_VERSION_EXISTS`).
- **The version chain.** The rows file is written last, so a version is complete when it is there; a render cut
  short before it is skipped, and a complete version that has lost a file is refused (`RENDER_FILE_MISSING`). Each
  rows file binds the previous complete version's rows file by sha256: S9's record is replaced at every render and
  names only the current version, and the chain is how S10 reaches an older version's files from the recorded
  current one. No change to `records.run_stage` was needed.
- **Frozen first-render proposals (E7, D-20261112-a578f6)**: each item's proposal as it was the first time it was rendered as proposed
  (release 1 has no "proposed and tested"), its material part (§13.4: disposition, destination, operation targets,
  behavior contract) and its wording's sha256. A later version carries every earlier entry unchanged and adds only
  new ones; frozen proposals changed after their render are refused (`FROZEN_CHANGED`). S10 computes the overturn
  rate against them (K3).
- **Model text kept in its place**: a one-line field has every whitespace run, newlines included, made one space, so it
  never starts a line; multi-line content sits in a fence longer than any backtick run it holds, and a line shaped like
  an owner-block marker inside it gets a leading backslash, the one change made to it.
- **A refused render** leaves S9's record failed (the shared mechanism replaces a stage's record at admission), and
  S10, whose inputs are S9's recorded outputs, waits for a render that succeeds.

## Where S9 is declared to the gates that judge it

Each site S9 adds is registered with its reason where the guarding module keeps them, not exempted:
`runlib/census.py` `READER_EXCEPTIONS` (S9 declares census.json as an input and reads its per-source `sources`, no
row); `runlib/controls.py` `READERS` (S9 reads which candidates S5 planted, so a proposal for one is accounted as a
control and never rendered; the review is the owner's, read by no judge); `runlib/dispatch.py` `SCRIPT_RUNS` (the
suite runs `distill.py render` as a child); `tables/ledger_readers.json` `mentions_only` (the run's supervisor
ledger, a different file; the legacy entries are handed to S9 by `lifecycle_intake.ledger_of`). And
`gates/check-driver-dependencies.py` now takes `session-distill/grammar` as a local package of the driver and scans
its modules: S9 is the first driver module to import it, and a local package nobody scans would be a hole. A planted
undeclared import inside it fails by name.
