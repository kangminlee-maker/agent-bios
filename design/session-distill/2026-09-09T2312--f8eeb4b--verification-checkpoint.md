## Dated corrections and unresolved measurement defects

The original Codex collector joined commentary and final-answer text. In pilot
cell `6b3c20505e0cb5b4750d8ad8`, a false missing-import diagnosis occurred in an
intermediate update; the final answer no longer made that claim. An earlier
progress statement incorrectly called it a final-answer defect. The saved host
rollout distinguishes these phases. The updated collector and assessor retain
intermediate updates separately and use only `final_answer` as final. The actor
is not rerun to fix a collection defect; affected judgment packets are rebuilt.
The original pilot runner is preserved as `pilot/runner-source.py`, whose hash
matches its manifest. New-run manifests pin the changed runner separately.

The first artifact check reported 120 passes, 14 failures and one exception
among 135 usable cells. These are not yet corpus-quality counts. Four patterns
need adjudication against the public request and actual fixture consumers:

1. A richer run record may demonstrate the correct scoped execution while
   failing an exact flat JSON expectation.
2. The layout control may supply measurements but no renderer that consumes a
   repair, making a changed measurement a false positive and an honest stop a
   false negative.
3. A corrected reporting script may write the requested output file instead of
   also printing JSON to stdout; the checker assumes stdout.
4. A control may update the reporting script to produce the requested output
   while the checker silently requires every original input to remain unchanged.

These are hypotheses, not settled excuses for failed actions. Fresh GPT
frontier adjudication was dispatched with the frozen public tasks, receipts,
consumers and a symmetric false-pass/false-fail rubric. Any invalid case must be
disclosed and replaced as a new frozen version, not silently repaired or counted
as an actor success. Existing actor evidence is preserved.

Both fresh semantic judges matched all six clarified calibration labels.
Only one initial case had a cross-provider three-arm result available without
the phase-capture issue; all three arms completed it correctly. That is not a
corpus winner, and the successful B/C actors did not demonstrably read the new
paragraph. Natural acquisition and supplied-text efficacy remain separate.
