## Defects fixed

1. **Duplicate keys were last-wins.** Every JSON file the evaluator reads now goes
   through one strict reader that refuses duplicate keys and non-finite constants. That
   covers the plan, catalog, baseline manifest, run file, host observations and the
   frozen case registry. `"B01": "failed", "B01": "passed"` no longer accepts P00.
2. **`in_flight` was untyped.** `records`, `bindings`, `in_flight` and
   `current_subjects` must be JSON objects. `in_flight` is now mandatory, because an
   absent map cannot be told apart from an unreported running attempt; the real P00 run
   already carries `in_flight: {}`. Its keys must be exact node ids with a nonempty
   `attempt_id`. An absent `requested_mode` still takes the plan's declared
   `execution.default_mode`; a present one must be a known mode.
   A malformed run is `status: invalid` as a whole, with exit 1.
3. **Wrong container types crashed with a traceback.** The run-shape check above
   covers the reported inputs. Record fields `cases`, `evidence_classes` and `artifacts`
   that are present but not objects reject only their node. A bound case map that is not
   an object of string family ids is `malformed bound case map`. `AttributeError` is in
   the command-line backstop, which now always prints a JSON body.
4. **Text was read in the locale encoding.** Every text read and write in both
   programs names UTF-8. Output is ASCII-escaped JSON, so it is encodable on any console.
5. **Refusals the helper never exercised.** The helper gained controls for the
   evidence path, binding completeness and identity, frozen-registry completeness,
   host observations, bundle identity and every structural refusal.
6. **Three divergent receipt-refresh walkers** are now one `Fixture.refresh_receipts`,
   and the plan digest is computed once per fixture.
