## Traps this session paid for

- **Do not edit `gates/check-parity.sh` while it runs.** Bash reads a script incrementally, so
  inserting lines moves its read position into the middle of an earlier line. One run ended
  with `FAIL: could not provision the textual venv` after every test had passed, with a healthy
  venv; the identical tree passed on the next run. The same holds for any file a running leg
  reads: keep new work in a scratch directory until the run ends.
- **A unicode escape in Python source can arrive decoded.** `€`, `"` and `\`
  written through the editing tool landed as the characters themselves and broke the file. Build
  such strings from code points or byte literals, and look at the bytes (`cat -v`) afterwards.
- **A manual umbrella run and the hook's run are each about eleven minutes**, and only the hook
  judges the index. Run the fast gates by hand, then let the commit be the full run.
- **Revert the rule, not only the test.** Code whose tests passed first time had eight rules no
  test noticed. Five were redundant and three were untested.
- zsh: `echo ======` is an expansion error, not a separator.
