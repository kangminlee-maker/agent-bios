## The one rule the whole exercise turned out to be about

**A rule a schema can state is stated there.** It began as a convenience in C04 and became the
measure of whether a contract had been written or merely described. Each of these is a refusal a
later implementation cannot forget, because the record that would violate it cannot be written:

| Where | What cannot be written down |
| --- | --- |
| `c04_role_projection` | a knowledge or memory source inside a behavioural projection |
| `c05_choice_record` | a partial replacement; `extent` is fixed to `whole` |
| `c05_application_preference` | a preference keyed by a session, or without its participants and their lineage |
| `c06_reader_envelope` | a retained-body claim carrying a digest but not its qualifications |
| `c06_reader_result` | an empty answer that reads as a denial; seven standings are one enum |
| `c06_pending_question` | the answer itself, on either the question or the resume |
| `c07_preparation` | task support that reads as satisfied when no task was requested |
| `c08_governing_policy` | a policy that counts the requester, a recorded author or a sponsored agent |
| `c08_founding_proposal` | a solo Team selected by the absence of a reviewer |
| `c08_lifecycle_action` | a closure with no surviving stewardship, or a purge promising one global outcome |
| `c09_transfer_envelope` | a delta with no baseline, or trust from a key the package carries about itself |
| `c10_custody_commitment` | a copy count in place of naming who holds what |
| `c10_retention_plan` | a promised body that is also evictable |
| `c11_answer_evidence` | an answer that does not name what separated a person from the host's automation |
| `c12_route_outcome` | a fixture result reported as a real run |

The three that carry the most weight later are C08's independence, C11's origin and C12's mode,
because each is a place where an implementation under pressure would otherwise have written the
convenient thing.

## What the twelve do not yet settle

- **The binding records are not written.** Signature, unlock, storage, bridge and host bindings
  are still only the spikes' `RESULTS` files. The refusal names those spikes observed —
  `backup_set_incomplete`, `backup_set_damaged`, `connection_profile_mismatch`, `host_not_exact`,
  `origin_not_exact`, `origin_required`, `client_token_missing`, `client_token_unknown`,
  `preflight_refused`, `signature_invalid`, `signer_not_permitted`, `tool_absent` — have no owning
  module, so the error table does not hold them.
- **U13 to U16 are not written**: the source manifest and authoring-home modes with the starter
  package inventory and its nine role examples; the subject-resolver manifests and the case
  registry; entrance routing, the closed terminal and locale list and the first-exposure protocol;
  the activated-session routing contract.
- **The operation names are illustrative.** `memory.record.publish`, `access.transition`,
  `role.project` and the rest show the pattern. The closed list is U10's and U11's.
- **`workenv/` is still absent from `package.json` `files[]`**, which U9 changes together with the
  boundary leg and its planted-violation control (`D-20260920-7989fe`).
