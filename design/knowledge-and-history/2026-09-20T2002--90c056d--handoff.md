  slug as a substring of the path, so `access_decision` failed on `decision`. Avoid
  `agent-launch`, `learn`, `redact`, `instructions`, `pkgid`, `domains`, `session-distill`,
  `ontology`, `decision` and `hygiene` in every schema, example and module name — C04 and C05
  are where this bites next. Values inside a file are not paths and are not matched. Run the
  lexicon gate after `git add`, before the commit, or the eleven-minute hook finds it for you.
- **A result example needs its request example.** `examples.check` holds each `operation_result`
  to an accepted `operation_request` example by id and digest, so write the request first and
  take the digest from its bytes, as the author tool does.
