## Correction to the handoff's S5 step 3 (dated 2026-08-26)

The handoff expected `whence -v claude → …/agent-launch/shell.zsh` after a reassert. That is
wrong in exactly the shell the reassert repaired: zsh annotates "from FILE" only for functions
defined while sourcing a file, and `_agent_launch_define` redefines both entrypoints at runtime,
so after any reassert `whence -v` shows no source for `claude` *or* `codex`. Read as a check,
it would report a repaired shell as "not ours" — a false signal. The live check in
`install.sh verify` therefore reads the body instead:
`print -r -- "$functions[claude]" | grep -c _agent_launch_dispatch → 1`. `whence -v` remains a
valid check only in a shell that was never shadowed.
