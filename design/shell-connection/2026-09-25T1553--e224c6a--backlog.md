| --- | --- |
| §1 Shell connected by default | A first install does not connect zsh (`_shell_paths` returns `[]` without a connection), so a bare `claude` or `codex` in a new terminal does not open the launcher and nothing says so. `test_default_off_and_help_names_real_entrypoints` pins the current behaviour. |

pin the old behaviour and would flip on adoption. §8 asks for a reply per item.
