## Next work — findings 4, 6, 7 from the multi-lens review

These three were deliberately left together because they touch one contract in
one file. Fixing them separately risks each one's controls invalidating the
others'.

- **#4** `check_ledger`'s required-field list is a strict subset of `STAMPED`, so
  a row missing a stamped field passes `--check` and then renders, or fails
  `--render`. Three exit routes, one validator gap.
- **#6** the ledger gate passes over an empty, absent, or tail-truncated ledger.
  `read_ledger` returns `[]` for a missing file, so `rm decisions/decisions.jsonl`
  yields `--check: OK (0 records)`. A self-test control currently cements the
  empty-is-clean behaviour.
- **#7** `split_span` counts only gaps *between* actions inside a span. The
  interval from the span start to the first action, and from the last action to
  the span end, are counted as neither active nor idle — silently discarded,
  which the file's own docstring forbids.
