# Build record — the criterion stage landed

Implements the same-day launcher-stage design on branch `review-defect-criteria-launcher`
off main at 12914d0. All seven build steps ran in design order; every control below was
seen to FAIL by name under a planted violation before its green, and the four load-bearing
fixes were each reverted once to prove their control notices.

## What was built (launch/agent-launch.py unless stated)

- **Constants**: `CRITERION_CLAUSE_MARKER` ("; criterion ") + `CRITERION_CLAUSE` (core
  constant, never a slot), beside the severity constants; `CRITERION_RECORD_SCHEMA`
  "ReviewCriterion/v1" + record marker; the criterion document grammar
  (`CRITERION_KEYS`, golden keys/kinds/minimums, provenance labels);
  `RECEIPT_CRITERION_ENV` "REVIEW_CRITERION_SCHEMA" beside the receipt env family.
- **Preset toggle**: `criterion` boolean parsed in build_plan (non-boolean refused by
  name), stored on the plan, threaded — never global — through
  resolve_review_for_plan → resolve_composable_review → _resolve_one →
  render_review_method. `routed_preset_names` counts `criterion` presence, so a
  criterion preset cannot be shadowed by a saved user preset (which cannot reproduce
  the field).
- **Render**: `criterion_clause(active)` appended inside the seat bracket BEFORE the
  severity clause (whose parser consumes everything after its marker); the marker joins
  the template-literal refusals, the formatted-body slot-value refusals, and the
  rendered-row plan-marker check. No INSTRUCTION_SLOTS or METHOD_KEYS change; the
  three i18n slot restatements are untouched because the slot vocabulary is untouched.
- **Subcommands**: `--compile-criterion FILE OUT` (validates the decidable subset —
  closed keys, all required, ≥2 classes, exactly one stop class ∈ classes, ≥2+/≥2−/≥1±
  goldens each with ISO date + measured/constructed provenance — publishes the
  canonical schema atomically, prints the packet record line + digest);
  `--check-findings RESULT SCHEMA` (accepts only a schema equal to compiling its own
  enum; refuses class-less, out-of-enum, unknown-key, empty-prose rows by name);
  `--check-schema-flag HOST` (probes the resolved backend binary for the host's
  structured-output flag — codex `exec --output-schema`, claude `--json-schema`;
  absent is exit 4, a finding, not an error). All three hostless, like the receipt
  subcommands.
- **Receipts**: emission under `REVIEW_CRITERION_SCHEMA` validates the result against
  the compiled schema BEFORE writing — a refused result earns no receipt, and only a
  successful dispatch (exit 0) is validated and stamped, so a failure receipt is never
  erased and never falsely claims validation. The receipt gains one optional key
  `criterion_schema_sha256` (hash form checked in the shared structure door; fold
  agreement includes it, presence counted); `--verify-receipts --packet` detects the
  discipline from the plan rows' snapshotted instructions, extracts the packet's
  ReviewCriterion/v1 record (absence/malformed/second record each refused by name),
  recompiles the schema — double-compile proven byte-identical — and refuses a receipt
  whose digest was compiled from any other criterion; a packet-less adjudication of a
  criterion plan discloses UNBOUND, and a criterion-less plan renders byte-identically
  to today.
- **Goldens** (gates/capture-review-goldens.py + gates/goldens/review-matrix.json):
  three additive scenarios — criterion-base-only, criterion-base-plus-both,
  err-criterion-non-boolean — 121 → 126 cells; the pre-existing 121 proven
  byte-identical by set comparison against HEAD's golden, and `--check` green before
  and after.
- **Gate leg** (gates/check_parity.py `launcher_review_criterion`): subtraction proof
  (toggle-on minus the constant equals toggle-off), runtime-named canary with a
  non-identity severity map (method-blindness + clause-before-severity ordering),
  slot-value spoof and template-literal refusals, toggled-plan row coverage, routed
  check, the full CLI chain against fake backends, and the four verify bars end-to-end
  through real emit → fold → verify artifacts.
- **Prose**: the guide's enum-enforcement rank 3 rewritten in place (EN + ko + both
  generated mirrors) — the channel now exists, so the "deliberately not part of this
  guide" paragraph would have been stale the moment this landed. The stale
  "192 projections" comment in gates/check-parity.sh now points at the artifact
  instead of carrying a count.

## Controls seen to fail, then pass (four faithful reverts)

1. `criterion_clause` planted to return "" → 7 leg failures by name (render
   subtraction, canary blindness, plan rows, bound/unbound disclosure, foreign digest,
   bare packet) — the first planted run also exposed and fixed a leg defect: the
   ordering check crashed instead of refusing when the clause was absent.
2. Emission validation bypassed (`if False and violations`) → "an unclassified finding
   earned a receipt", naming the written file.
3. Verify's digest comparison disabled → "a receipt stamped with a foreign schema
   digest was not refused".
4. `criterion` removed from `routed_preset_names` → "a criterion-toggled preset is not
   routed".

Plus the golden instrument test: `--check` red before re-capture (new cells missing),
green after, with zero changed pre-existing cells; and probes through the real CLI —
compile/refusals, double-compile byte equality, emit refusal with empty receipt dir,
prose-route emit unchanged with the env unset, both installed binaries probing PRESENT
for their schema flags (codex-cli 0.146.0, Claude Code 2.1.235).
