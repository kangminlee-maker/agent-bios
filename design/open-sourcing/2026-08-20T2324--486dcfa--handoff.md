## Traps this session paid for (beyond AGENTS.md's list)

- **The pre-commit hook outlives the tool's 10-minute timeout.** A foreground
  `git commit` was SIGTERMed mid-gate (nothing was lost — the index survived and no
  half-state remained). Commit **detached**: `nohup bash -c 'git commit -F msg >
  log 2>&1; echo $? > done' &`, then watch for the `done` file. Background waiters
  are killed routinely by the harness; the detached commit is not.
- **`bash x.sh > log 2>&1; echo "exit=$?"` reports the ECHO's status.** The harness
  said exit 0 while the suite had FAILED. Read the log, not the wrapper.
- **`ls -d $TMPDIR/prefix-*` silently returns nothing at ~43k matches**, which read
  as "no temp-dir leak" when there were 43,001. Count with `glob` in python when a
  set may be large.
- **A gate's own fixtures trip the gate.** Any URL literal added to a shipped file —
  including in a comment or a self-test fixture — fails the urls leg. Spell fixtures
  in pieces (`"https:" "//"`) or use a `.test` host.
- **Mutation controls anchor on source text.** Every refactor of
  `learn/collect-learning.py` broke several of `check-endpoints.py`'s planted
  mutations (indentation moved, an except tuple changed). When the self-test says
  "mutation source not found", that is the control asking to be realigned, not a
  defect.
