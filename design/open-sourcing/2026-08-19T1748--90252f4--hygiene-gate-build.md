# Build record — the content-hygiene gate (roadmap step 1)

Implements step 1 of the same-day frame-critique roadmap on branch
`content-hygiene-gate`. Scoped by measurement before any code: the shipped
distribution was scanned first, and the result reshaped the step.

## The measurement that reshaped the step

Scanning the real v0.13.0 tarball's 80 payload files plus the ko corpus trees
(2026-08-19): **zero** org identifiers (day1 / day1co / day1company / ai-litmus /
fixture emails), **two** author identifiers, both legitimate (the MIT LICENSE
copyright line; package.json's account and repository fields). The instrument was
held to the known-opposite rule: every pattern shown firing on known-positive
files (the open-sourcing backlog record, the intake fixture) and the `day1`
exclusions (`day1co`, `day1-agent-bios`) shown not to fire.

Consequence: the backlog's 81 tracked `day1` references live almost entirely in
`design/` and `decisions/` — trees that are now permanently org-private after the
re-homing — so step 1 is **regression prevention for an already-clean scope**,
not a cleanup, and the burn-down allowlist the roadmap anticipated starts EMPTY.
The sink's day1 coupling is structural (a dashboard-owned config home), invisible
to a lexical gate and correctly left to roadmap step 2.

## What was built

- **`gates/check-hygiene.py`** — subjects derived from package.json `files[]`
  (npm-style expansion) + `README.md`/`LICENSE`/`package.json` + the ko corpus
  trees (119 files today), asserted non-empty and asserted to contain
  `claude/CLAUDE.md`. Three pattern classes; org identifiers have NO escape;
  author identifiers are excused by the `(private)` marker on the line or a
  per-reason `EXEMPT` (file, pattern) pair; an exemption whose file no longer
  carries the pattern fails as stale. `--self-test` copies the real subject set,
  runs the positive control first, then plants: an unmarked org reference, a
  MARKED org reference (still refused — the marker must not excuse org), bare
  `day1` plus its exclusions, an unmarked author identifier, the same line
  marked (passes — the marker branch is live and pattern-scoped), an author
  token inside the exempted LICENSE (passes), a copyright line without the
  licensor (stale exemption fires), and the empty-subject refusal.
- **The private-binding marker made real** — the literal `(private)` now has an
  instance (the global's response-language bullet, EN + ko), a machine reader
  (the gate's author-identifier escape), and a rewritten README Adopting
  paragraph naming both directions (marked lines are the swap checklist; the
  gate enforces the rest). The backlog had found the marker was a README
  convention with zero in-guide instances.
- **Lexicon**: `private binding` concept + the `hygiene` concept home
  (`gates/check-hygiene.py`) added in the graph, LEXICON.md re-emitted. The
  graph edit was preceded by a byte-identical round-trip probe after a first
  attempt reformatted the whole file (caught by diff --stat, restored, redone
  in the original format).
- **Wiring**: a parity-umbrella stanza (scan + self-test) beside the lexicon
  gate's; AGENTS.md's umbrella inventory names it.
