## The one that changed a design

Four contract findings — a stat-then-unlink window at both break and release, a
`{pid, host}` pair that cannot establish ownership across hosts or pid
namespaces, a reused pid making a crashed owner look immortal, and a lock
pathname visible before its owner metadata was written — share one root: **the
code asked a FILE whether its owner was still alive.** A file cannot answer that,
so every version inferred it, and each inference had its own failure.

`fcntl.flock` asks the kernel. `STALE_S`, the age test, the liveness probe, the
owner comparison and the unlink all delete; a crashed holder's lock frees in
0.0 ms with no staleness rule to wait out. The limits are now written rather than
implied: advisory, host-local, and not to be trusted over an NFS home. The
`{pid, host}` still written into the file is diagnostic only, so the refusal can
name a pid to look for.

That supersedes `D-20260825-1caeb3`, recorded earlier the same day. Both are in
the ledger; the newer one names the older.

Three assumptions were measured before the design rested on them, on darwin: two
open file descriptions in one process do exclude each other, a dead holder's lock
is free immediately, and a live holder excludes while the pid in the file stays
readable by the contender.

## Confirmed by execution, not taken on the reviewer's word

- **`learn --no-upload` ran a core the provisioner had just refused.** A marker
  inside the core's `main()` printed while the wrapper reported failure. The
  T3 exception collapsed "cannot vouch for the slot" with "cannot vouch for the
  core"; they are different exit codes now (`EXIT_CORE = 3`) and only the first
  admits a local capture. **The marker must sit inside `main()`** — at module
  scope it fires on the provisioner's own import and reads a refusal as an
  execution, which is how the first probe reported a fixed defect as still live.
- **Excluding `__pycache__` from the pin digest left executable bytes unbound.**
  A planted cache whose header matches the source's mtime and size changed a
  function's return value while the source's sha256 never moved — CPython does
  not read the source in that case. Presence is a failure now, and three places
  stop writing caches (`provision_slot`'s `sys.dont_write_bytecode`, and
  `PYTHONDONTWRITEBYTECODE` from `bin/` and `test/e2e.sh`).
- **`install.sh:43-53` resolves its own symlink and takes `REPO` from the link's
  directory**, so a file replaced by a link to identical content ran a core from
  outside the recorded tree with the digest unchanged. Symlinks are hashed as
  their target string now.
- **`learn --self-test` returns before the `--no-upload` branch** and posts on
  its own, so the flag the exception rests on does not govern it. It is excluded
  from the exception.

## Two claims of mine the review refuted

Worth keeping, because both were stated in a packet as established fact:

1. "`http_post` is reached only from `drain_uploads`" — `_self_test` reaches it
   directly. The wrapper's "sends nothing" promise did not cover that path.
2. "the record goes out on a later capture" is true only in the eventual sense.
   `drain_uploads` selects every unsettled row but processes at most 25 and stops
   on budget or a transient response, so the *immediately* next capture is not
   guaranteed to send it. The e2e now proves three queued records arrive; the
   README says "a later capture", which survives the narrowing.

## Closed by narrowing rather than by fixing — read this before re-filing it

**Cross-host slot locking is not promised.** `flock` is host-local, and the
finding about ownership across hosts is closed by declaring the scope in
`README.md`, not by making it true. If two machines ever share one home
directory, this is open again — and it belongs with T4, since the answer is a
single-file slot rather than a better lock.

## Traps this round paid for

- **`"$1:lib/path"` in zsh eats `:l` as a parameter modifier**, so a fixture
  builder silently produced no file — and the stale fixture from the previous
  attempt was still on disk and reported green. Delete fixtures before rebuilding
  them, and assert the mutation landed.
- **`"$(yn cmd >/dev/null 2>&1)"` swallows `yn`'s own answer**, so the row could
  only ever be empty. A check that cannot report success is not a check.
- **`$TMPDIR` ends in a separator on macOS**, so a harness-composed path carries
  a doubled slash the collector's does not. Compare normalised paths when the
  claim is "the same file".
- **`agent-bios verify` exits non-zero in a bare sandbox** for reasons unrelated
  to blocking, so it cannot answer "was this command permitted". `help` can.
- **A control that raises takes the controls after it down unread.** Two rows
  had to be made defensive before the revert proofs could be read at all.
