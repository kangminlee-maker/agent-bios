# Using decision memory

A session activated by agent-bios arrives with a short memory usage contract that points here.
This guide is the procedure behind it.

## The rule

- Decision memory holds choices a person or a team made, with their reasons and the
  alternatives they closed. Read it as context. Never apply it on the person's behalf.
- When a piece of actual work would rely on current choices that conflict, ask the person which
  one applies, in this conversation. Do not choose for them. A tool approval, a hook's reply or
  your own summary is not their answer.
- Keep doing the work that does not depend on the conflicting choice.

## What this installation provides now

- A session's preparation names the memory sources it was composed with and the point each one
  was read at. It does not carry their contents.
- Reading decision records for a use, and recording a person's answer, are not available in this
  version. Where a use needs them, say that the decision context is unavailable. Do not guess it.
